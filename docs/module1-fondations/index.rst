====================================
Module 1 — Fondations JavaScript
====================================

JavaScript est un langage **interprété**, **dynamiquement typé** et **orienté événements**. Ces deux séances posent les bases absolument indispensables pour tout ce qui suit.

.. admonition:: Pourquoi ces fondations sont critiques
   :class: important

   80% des bugs JavaScript viennent d'une mauvaise compréhension des bases : une variable `undefined`, une fonction appelée avant d'être déclarée, une boucle qui ne s'arrête pas... Maîtriser ce module, c'est éviter la majorité des erreurs de débutant.
