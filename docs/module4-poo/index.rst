====================================
Module 4 — Programmation Orientée Objet
====================================

La **Programmation Orientée Objet** (POO) est un paradigme qui organise le code autour d'**objets** regroupant des données (propriétés) et des comportements (méthodes). JavaScript supporte la POO depuis ses origines avec les prototypes, et depuis ES6 avec une syntaxe ``class`` claire et lisible.

.. admonition:: Pourquoi la POO ?
   :class: note

   Sans POO, un projet de taille moyenne devient rapidement un enchevêtrement de fonctions et de variables globales difficile à maintenir. La POO permet de **modéliser le monde réel** :

   - Un ``Etudiant`` sait se présenter, se valider, calculer sa mention
   - Un ``Catalogue`` sait filtrer, trier, ajouter, supprimer des étudiants
   - Une ``Modal`` sait s'ouvrir, se fermer, afficher n'importe quel contenu

   Chaque objet est **autonome**, **réutilisable** et **testable** indépendamment.
