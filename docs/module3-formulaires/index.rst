====================================
Module 3 — Formulaires & Validation
====================================

Un formulaire non validé est une porte ouverte aux erreurs et aux données corrompues. JavaScript permet une validation **instantanée**, **côté client**, avec un retour visuel immédiat — bien avant que les données n'atteignent un serveur.
